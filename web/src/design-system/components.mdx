# Components

The shared controls in `web/src/components`. Use them instead of restyling native elements; each story below is the component's own.

## Button

`rounded-md`, `text-label`. Primary is `orange` for the one action; outline is `card` with a `border` for filters, paging, and secondary actions.

<Canvas of={ButtonStories.Variants} sourceState="none" />

`default` is 32px, `touch` 44px; `icon` and `icon-touch` are square.

<Canvas of={ButtonStories.Sizes} sourceState="none" />

A disabled primary turns `gray-3` with `gray-7` text; other variants dim to 50%.

<Canvas of={ButtonStories.DisabledVariants} sourceState="none" />
