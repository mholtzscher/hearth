# Record command attempts without making commands durable

Hearth will record each immediate Command attempt and terminal outcome in core-owned SQLite so operators can diagnose behavior and a later product interface can present history. This record is audit evidence rather than executable work: delivery remains expiring Core NATS request/reply, startup marks unfinished attempts interrupted, and the core never replays or redispatches them. A matching linked Observation marks an active Command satisfied in the same transaction as its receipt and canonical State projection so history cannot disagree with the evidence behind State.
